## QR PDF Generator

Простое GUI-приложение на Python, которое принимает список строк и создаёт PDF-файл с QR-кодом и подписью для каждой строки.

### Запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите приложение:
   ```bash
   python main.py
   ```

### Использование

1. Вставьте список строк (по одной на строку) или загрузите их из Excel (кнопка «Загрузить Excel» читает первый столбец активного листа).
2. Нажмите «Сгенерировать PDF» и выберите папку — файл сохранится с именем вида `Коды_коробов_YYYY-MM-DD_1.pdf`.
3. Готово — в PDF каждый QR расположен на отдельной компактной странице A6 с подписью.

### Сборка EXE

1. Установите зависимости и PyInstaller:
   ```bash
   pip install -r requirements.txt
   python -m pip install pyinstaller
   ```
2. Запустите скрипт сборки:
   ```bash
   build_exe.bat
   ```
3. Готовый `QRGenerator.exe` появится в папке `dist` — его можно передать коллеге.
